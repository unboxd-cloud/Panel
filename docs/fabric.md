# Fabric as Building Block

Fabric is the building block of Unboxd Panel.

A box is bounded.
A fabric is open.

The control panel operates fabric units, not abstract dashboards.

## Canonical Definition

```text
Fabric = Open Building Block for Governed Digital Operations
```

A fabric is a composable operating unit that can emit, receive, store, reconcile, and expose state through explicit protocols.

It is not only a mesh.
It is not only a graph.
It is not only a box.
It is the controllable building block from which hybrid operations are composed.

## Why Fabric

A box is useful because it creates a boundary.

But a closed box is incomplete for operations.

A real operational unit must:

- expose protocols
- accept contracts
- emit events
- store state
- detect drift
- apply policy
- reconcile changes
- prove audit
- compose with other units

That unit is fabric.

## Fabric Shape

```text
Protocol Boundary
  -> Contract
  -> Identity
  -> Event Stream
  -> State Store
  -> Policy Gate
  -> Execution Adapter
  -> Reconciliation Loop
  -> Audit Trail
```

## Fabric and Panel

```text
Fabric = Building Block
Panel  = Control Surface
```

Panel does not invent the fabric.
Panel observes, governs, composes, and controls fabric units.

## Fabric and Stable State

Fabric exists to maintain stable state.

```text
Declared State
  -> Observed State
  -> Drift
  -> Policy
  -> Execution
  -> Reconciliation
  -> Stable State
```

## Fabric and Hybrid Cloud

A fabric unit can represent:

- a server
- a VPS
- a Kubernetes cluster
- a namespace
- a tenant
- a service
- an agent runtime
- a database
- an identity domain
- a workflow
- an edge location
- an on-prem environment
- a cloud account

Each fabric unit must be identifiable, observable, governable, and reconcilable.

## Fabric Contract

Every fabric unit must answer:

1. What is its identity?
2. What protocols does it expose?
3. What contracts does it accept?
4. What state does it declare?
5. What state does it observe?
6. What drift can it detect?
7. What policies govern it?
8. What actions can it execute?
9. What events does it emit?
10. What audit trail proves it?

## Non-Negotiable Rule

A fabric unit cannot be controlled if it cannot be identified, observed, and reconciled.

## Feature Rule

```text
Feature = Fabric Unit + Protocol + Contract + State + Drift + Policy + Execution + Audit + UI + Service Operation
```

## Final Cut

```text
Unboxd Panel controls fabric units.
Fabric units compose stable-state hybrid operations.
```
